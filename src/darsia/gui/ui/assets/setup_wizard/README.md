# Setup wizard illustrations

Drop an image here named after a wizard step and it is shown on that step
automatically — no code change needed.

Recognised names (first match wins, in this order):

| Step | File |
| --- | --- |
| Data & results | `data.gif` / `data.png` / `data.jpg` |
| Rig & corrections | `series.gif` / `series.png` / `series.jpg` |
| Protocols | `protocols.gif` / `protocols.png` / `protocols.jpg` |
| Review & finish | `review.gif` / `review.png` / `review.jpg` |

Animated GIFs play automatically. Stills wider than 560 px are scaled down, so
ship them at roughly that width to keep the file small.

Nothing is bundled yet: a screenshot of a different part of the app tends to
confuse more than it helps, so these slots are waiting for purpose-made
diagrams (e.g. what "baseline image" means, or the four start-reference
choices side by side).
